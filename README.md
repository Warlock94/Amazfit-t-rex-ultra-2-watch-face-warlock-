# TACTICAL WARLOCK 480

Версия 1.0.0. Циферблат для Amazfit T-Rex Ultra 2 (круг 480×480, Zepp OS 5 / 6).

## Сборка одной командой

Нужны Node.js 18+ и аккаунт [Zepp Developer Console](https://console.zepp.com/).

```bash
npm install -g @zeppos/zeus-cli
```

Перед публикацией замените `app.appId` в `app.json` на ID, который выдала консоль. Для локального preview можно оставить текущий.

```bash
zeus login
zeus build
```

Готовый пакет появится в `dist/`. Современный CLI кладёт туда `.zab` (это и есть устанавливаемый пакет Zepp OS; старое расширение `.zpk` Zeus больше не выпускает).

Отправка на часы:

1. Телефон с приложением Zepp, часы сопряжены.
2. Режим разработчика: Профиль → Настройки → О приложении, несколько нажатий по номеру версии.
3. В папке проекта: `zeus preview`.
4. На часах удерживайте циферблат и выберите TACTICAL WARLOCK 480.

`deviceSource` в `app.json`: 10879232, 10879233, 10879235 (T-Rex Ultra 2, все региональные ревизии).

## Что берётся из системы

| Данные | Как |
| --- | --- |
| Часы и минуты | `IMG_TIME`, обновляет система |
| Секунды | `IMG_TIME` / `second_*`, 1 раз в секунду только при включённом экране |
| День, месяц, год | `IMG_DATE` |
| День недели | `IMG_WEEK`, русские подписи, индекс 0 = воскресенье |
| Пульс | `TEXT_IMG` + `HEART`; шкала — по событию нового замера |
| Шаги и цель | `TEXT_IMG` + `STEP` / `STEP_TARGET`; полоска — по событию шага |
| Батарея | `TEXT_IMG` + `BATTERY`; сегменты — по событию заряда |
| Температура | `TEXT_IMG` + `WEATHER_CURRENT` |
| Иконка погоды | `hmSensor` WEATHER, `forecastData.data[0].index`, не чаще раза в 30 минут |
| Будильник / уведомления | См. ниже |

Пустых данных система не подменяет случайными числами. Нет замера пульса — шкала пустая, число остаётся на системном виджете (часто пусто, не «0» выдуманный). Нет прогноза — иконка прозрачная, температура на системном виджете.

## Чего API циферблата не даёт

- Счётчик непрочитанных уведомлений. Колокольчик на циферблате — рисунок макета, не бейдж. `IMG_STATUS` умеет только будильник, DND, блокировку и разрыв Bluetooth; если включить его как колокольчик, иконка пропадёт, когда будильник выключен.
- Непрерывная ЭКГ. Шкала показывает зону последнего замера.
- Погода класса `@zos/sensor` Weather — это API приложений, не циферблата. Здесь используется датчик циферблата `hmSensor.id.WEATHER`.
- Всегда включённый экран с секундами специально не включён: секунды на AOD сажают батарею.

Если дни недели сдвинуты на один, в `assets/week/` поменяйте порядок `0.png`…`6.png`. Сейчас 0 — воскресенье.
